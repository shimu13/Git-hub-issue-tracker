                                   Answer to the questions



1️⃣ What is the difference between var, let, and const?

Ans: var- It`s a function scoped and reassignable.

let- It is the modern version of var. It`s  a block scoped only inside  and reassignable. 

const- It is block scoped and Value must be assigned at declaration; objects and arrays can be mutated, but cannot be reassigned.

2️⃣ What is the spread operator (...)? 

Ans: The spread operator expands an array or object into individual elements.

3️⃣ What is the difference between map(), filter(), and forEach()?

Ans: map(): It`s returns a new array and transform each element.

filter(): It`s filter based on condition and returns a new array with only matching elements.

forEach(): Just iterate and perform side effects.

4️⃣ What is an arrow function?

Ans: An arrow function is a shorter way to write a function in JavaScript. It uses the => syntax and is often more concise than regular functions.

5️⃣ What are template literals?

Ans: Template literals allow string interpolation and multi-line strings using backticks ` instead of quotes.
